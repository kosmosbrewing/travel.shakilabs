# 여행 준비 도구 · shakilabs

**▶ 라이브 서비스: <https://shakilabs.com/travel>**

항공 수하물 예산, eSIM·로밍 비교, 환전 수수료 비교 — 출국 전 비용 점검 도구 모음.

## 주요 도구

- [수하물 예산](https://shakilabs.com/travel/luggage)
- [eSIM·로밍 비교](https://shakilabs.com/travel/esim)
- [환전 수수료 비교](https://shakilabs.com/travel/exchange)

전체 서비스 12종: <https://shakilabs.com>

## 스택

Vue 3 (Composition API) · TypeScript · Vite · Tailwind CSS · 공유 UI `@shakilabs/ui`
정적 프리렌더/SSG로 배포하며, 계산 로직은 Vitest 경계값 테스트로 검증합니다.

## 개발

```bash
cd client
npm install
npm run dev
```
